# FixFlow AI tech stack

## Web frontend
React, TypeScript, Vite, React Router, Axios, Context API, Zustand, Tailwind CSS, Lucide React.

## Mobile
Flutter, Dart, Riverpod, Dio, flutter_secure_storage, image_picker, geolocator.

## Backend
C#, ASP.NET Core Web API, .NET 8, Entity Framework Core, Npgsql, JWT, FluentValidation, Swagger / OpenAPI.

## Database
PostgreSQL with pgAdmin 4. Database name: `FixFlow`. Local username: `postgres`.

## Agentic AI
.NET orchestration layer, LLM model adapter, structured JSON outputs, tool calling, human-in-the-loop approval.

## Testing
xUnit, Moq, React Testing Library, Vitest, Flutter Test.

## Version control
Git, GitHub, GitHub Actions.
